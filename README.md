# TOWER DEFENSE WALKING DEAD

## Splash Screen
- Le joueur peut et devrait sélectionner la carte 3 en appuyant sur le bouton choisir carte
- il peut ensuite appuyer sur START GAME

## Le jeu
- Le joueur peut acheter et placer une tour en cliquant sur la tour puis sur la case
- Le joueur ne peut pas vendre la tour 
- Le joeur peut augmenter la force et le rayon de la tour s'il a assez d'argent en cliquant sur la tour puis en appuyant sur le bouton de ce qu'il veut améliorer
- il y a un bouton AUTO : qui fais venir les vagues à l'infini tant que le joueur ne meurt pas 
- Le joueur peut appuyer sur vague suivante pour faire venir la prochaine vague si celle en cours est fini
- Le joueur peut appuyer sur option et faire pause / résumer 
- le joueur peut réinitialiser la partie mais le bouton ne fonctionne pas bien car les tours ne s'enlèvent pas
